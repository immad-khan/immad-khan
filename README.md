> ℹ️ **Setup note:** This isometric 3D graph is generated automatically via the [`github-profile-3d-contrib`](https://github.com/yoshi389111/github-profile-3d-contrib) GitHub Action. Add this workflow to `.github/workflows/profile-3d.yml` in your profile repo:
>
> ```yaml
> name: 3D Profile Generation
> on:
>   schedule:
>     - cron: "0 0 * * *"
>   workflow_dispatch:
> jobs:
>   build:
>     runs-on: ubuntu-latest
>     steps:
>       - uses: actions/checkout@v4
>       - uses: yoshi389111/github-profile-3d-contrib@0.7.1
>         env:
>           GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
>         with:
>           userName: immad-khan
>       - uses: stefanzweifel/git-auto-commit-action@v5
>         with:
>           branch: output
>           commit_message: "generate 3d profile"
>           file_pattern: "profile-3d-contrib/*.svg"
> ```
